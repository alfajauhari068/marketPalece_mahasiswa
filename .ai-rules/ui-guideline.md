# ui-guideline.md

Purpose
-------
Aturan visual dan pengalaman pengguna untuk antarmuka web aplikasi.

Key Points
----------
- Design tokens: color, spacing, typography defined centrally.
- Use accessible components; maintain contrast ratio >= 4.5:1 for text.
- Responsive rules: mobile-first, 12-column grid on desktop.
- Component library: Blade components + Tailwind utility tokens recommended.

Documentation
-------------
- Include example usage for primary components (cards, forms, modals).
