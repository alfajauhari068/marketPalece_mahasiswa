# Product Requirement Document

## Product Vision

Membangun marketplace jasa mahasiswa yang memungkinkan mahasiswa membangun personal branding dan melakukan transaksi profesional.

---

## Problem Statement

Masalah:

- Mahasiswa tidak punya platform internal
- Sulit membangun reputasi profesional
- Freelance tersebar di media sosial

---

## Goals

Primary:

- Marketplace internal kampus

Secondary:

- Portofolio mahasiswa
- Simulasi freelance

---

## Success Metrics

- Total user aktif
- Total jasa dibuat
- Total order selesai
- Rating rata-rata
- Conversion browse → order

---

## Core Features

1. Authentication
2. Profile
3. Service
4. Marketplace
5. Order
6. Payment Dummy
7. Review
8. Chat
9. Dashboard
10. Admin Panel

---

## Future Features
